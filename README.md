# REG-INSIGHT

AI-powered regulatory compliance analysis system.

## Week 1: Environment Setup & Document Ingestion

### Setup
1. Open VS Code in this folder
2. Select Python interpreter (with venv)
3. Run: `python test_installation.py`

### Project Structure
- `src/ingestion/` - PDF processing and chunking
- `src/embeddings/` - Vector generation and storage
- `src/retrieval/` - Semantic search
- `src/scoring/` - Gap detection and classification
- `src/explanation/` - LLM integration
- `src/ui/` - Streamlit dashboard
- `data/` - Document storage
